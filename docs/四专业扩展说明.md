## 机械、土木与工程力学

| 主题 | 模板 |
|---|---|
| 静力与运动（基础） | 牛顿第二定律、动能、动量、机械能守恒（以上共享）、力对点的矩 |
| 材料与变形（基础） | 轴向平均正应力、轴向工程应变、单轴胡克定律、等截面杆轴向变形、泊松比 |
| 梁与扭转（进阶） | 梁弯曲正应力、梁横向剪应力、圆轴扭转剪应力、圆轴扭转角、欧拉柱临界力 |
| 流体与水力（基础） | 不可压缩流连续方程、伯努利方程、静水压强、雷诺数、达西沿程水头损失 |
| 结构与土力（进阶） | 平面桁架节点平衡、梁单位荷载位移法、饱和土有效应力、莫尔—库仑抗剪强度、朗肯主动土压力系数 |
| 机械传动与振动（进阶） | 外啮合齿轮传动比、转轴功率、单自由度固有角频率、临界黏性阻尼系数、单自由度受迫振动方程 |

材料力学轴向应力以拉为正；土力学以压为正。弯曲正应力明确坐标与弯矩正向，圆轴扭转不能直接用于非圆截面。欧拉公式仅为理想细长线弹性柱的临界值；单位荷载法只计弯曲贡献。伯努利式不含泵、涡轮与损失；管流采用 Darcy 摩阻系数，等于 Fanning 系数的四倍。齿轮传动比保留外啮合反向的负号，角速度使用 rad/s。朗肯系数采用水平无黏性填土、光滑竖直墙及主动极限状态，水压力另计。

主要参考：[MIT 1.050 结构工程力学教材](https://ocw.mit.edu/courses/1-050-solid-mechanics-fall-2004/pages/readings/)、[MIT 3.11 材料力学](https://ocw.mit.edu/courses/3-11-mechanics-of-materials-fall-1999/)、[MIT 1.060 流体力学讲义](https://ocw.mit.edu/courses/1-060-engineering-mechanics-ii-spring-2006/pages/lecture-notes/)、[MIT 1.361 土力学讲义](https://ocw.mit.edu/courses/1-361-advanced-soil-mechanics-fall-2004/pages/lecture-notes/)、[MIT 2.003SC 工程动力学](https://ocw.mit.edu/courses/2-003sc-engineering-dynamics-fall-2011/)。模板中记录了对应章节／主题；共享条目保留原物理教材来源。

## 化学、化工与材料

| 主题 | 模板 |
|---|---|
| 计量与溶液（基础） | 物质的量浓度、溶质质量分数、理想气体状态方程（共享）、稀释守恒、反应进度与组分量 |
| 热力学与平衡（进阶） | 热力学第一定律（共享）、吉布斯自由能变化、活度平衡常数、标准自由能与平衡常数、积分范特霍夫方程 |
| 动力学与反应器（进阶） | 幂律反应速率、一级反应积分式、阿伦尼乌斯方程、理想 CSTR 体积、理想 PFR 体积 |
| 电化学与分析（进阶） | 电池能斯特方程、法拉第电解质量、比尔—朗伯定律、氢离子活度 pH、亨德森—哈塞尔巴尔赫式 |
| 传递与分离（进阶） | 一维菲克第一定律、一维傅里叶导热定律、牛顿对流换热、拉乌尔定律、二元相对挥发度 |
| 材料结构与性能（进阶） | 布拉格衍射定律、立方晶胞理论密度、霍尔—佩奇关系、线性热应变、二元两相杠杆定则 |

沿用吸热 Q>0、系统对外做功 W>0，即 ΔU=Q−W；化学教材常用的“外界对系统做功”符号不能直接混入。温度使用 K，能量单位须与 R 配套。热力学 K、Q 和活度均无量纲；ln 为自然对数，pH、缓冲式与吸光度用十进对数。反应物化学计量数为负，CSTR／PFR 采用 A 的生成速率 r_A<0，分母为 −r_A。布拉格角为 θ，区别于仪器的 2θ；杠杆定则中组成和相分数必须同为质量或同为摩尔口径。

化学式用普通 KaTeX 下标、上标和正体符号表示，沿用现有受限渲染规则，不引入新的反斜杠命令或用户 HTML。

主要参考：[OpenStax Chemistry 2e](https://openstax.org/books/chemistry-2e/pages/1-introduction)、[Michigan 反应工程教材配套资料](https://public.websites.umich.edu/~elements/6e/expanded/index.html)、[MIT 10.302 传递过程习题讲解](https://ocw.mit.edu/courses/10-302-transport-processes-fall-2004/pages/recitations/)、[MIT 10.32 分离过程](https://ocw.mit.edu/courses/10-32-separation-processes-spring-2005/)、[NIST 吸光度标准](https://nvlpubs.nist.gov/nistpubs/jres/76A/jresv76An5p469_A1b.pdf)、[Roylance 位错讲义，第 10 页式 7](https://ocw.mit.edu/courses/3-91-mechanical-behavior-of-plastics-spring-2007/dd1eb1e4a4f711f006fb6db74900e3e9_21_dn.pdf)、[Cambridge 两相杠杆定则](https://www.doitpoms.ac.uk/tlplib/phase-diagrams/printall.php)。

## 经济学与管理学

| 主题 | 模板 |
|---|---|
| 供需与弹性（基础） | 线性需求函数、需求价格点弹性、线性供需均衡价格、利润恒等式、边际成本 |
| 生产与市场（进阶） | 柯布—道格拉斯生产函数、劳动边际产出、利润内点一阶条件、勒纳加成指数、两商品预算约束 |
| 宏观核算（基础） | 支出法 GDP、当期价格 GDP、GDP 平减指数、固定篮子消费价格指数、实际利率费雪关系 |
| 增长与货币（进阶） | 离散增长率、单期复利终值、货币数量交换方程、简单支出乘数、索洛人均资本动态 |
| 项目与决策（进阶） | 单笔现金流现值、净现值、单产品盈亏平衡量、离散决策期望收益、线性规划标准最大化 |
| 运营管理（进阶） | 经济订货批量、确定需求再订货点、利特尔法则、M/M/1 服务利用率、PERT 活动期望工期 |

价格点弹性保留符号，通常为负；勒纳式采用 −1/ε_d。利润一阶条件不保证最优。GDP 与 CPI 采用教学核算口径，指数基期为 100；费雪关系使用精确乘积形式。复利、贴现与增长率使用小数，期间一致；净现值计入 t=0 的带符号现金流。数量方程是核算关系，简单乘数依赖无税收、无进口等假设。EOQ 排除缺货及数量折扣，Little 法则对齐系统边界，PERT 是单活动近似期望，不能直接解释成项目完工概率。

主要参考：[OpenStax 经济学原理](https://openstax.org/books/principles-economics-3e/pages/1-introduction)、[OpenStax 财务原理](https://openstax.org/books/principles-finance/pages/1-why-it-matters)、[OpenStax 管理会计盈亏平衡](https://openstax.org/books/principles-managerial-accounting/pages/3-2-calculate-a-break-even-point-in-units-and-dollars)、[MIT 14.452 经济增长](https://ocw.mit.edu/courses/14-452-economic-growth-fall-2016/pages/lecture-notes/)、[MIT ESD.273J 库存模型](https://ocw.mit.edu/courses/esd-273j-logistics-and-supply-chain-management-fall-2009/pages/lecture-notes/)、[MIT 排队系统](https://ocw.mit.edu/courses/1-203j-logistical-and-transportation-planning-methods-fall-2006/resources/lec5/)、[MIT 15.053 管理优化](https://ocw.mit.edu/courses/15-053-optimization-methods-in-management-science-spring-2013/pages/lecture-notes/)、[MIT 项目管理 PERT，第 44 张幻灯片](https://ocw.mit.edu/courses/1-040-project-management-spring-2004/97aa27438622aca8f4d56685302b2c98_l11dtrm2ilistic1.pdf)。

## 生物学

| 主题 | 模板 |
|---|---|
| 遗传与群体（基础） | 哈代—温伯格平衡、二倍体等位基因频率、二项分布（共享）、性别比例有效群体大小、遗传漂变频率方差 |
| 细胞与酶（进阶） | 米氏方程、双倒数米氏方程、希尔结合方程、稀溶液渗透压、一维菲克第一定律（共享） |
| 种群生态（基础） | 连续指数种群增长、逻辑斯蒂种群增长、离散世代几何增长、种群数量收支、洛特卡—沃尔泰拉捕食模型 |
| 生态多样性（进阶） | 熵／香农多样性（共享）、辛普森多样性指数、香农均匀度、Chapman 标记重捕估计、物种—面积幂律 |
| 生理与生物物理（进阶） | 单离子膜平衡电位、一维扩散均方位移、温度系数 Q10、菲克原理流量平衡、泊肃叶管流量 |
| 实验与传播模型（进阶） | PCR 理想扩增、qPCR 相对表达量、封闭群体 SIR 模型、SIR 基本再生数、累积发病比例 |

生物学香农指数共享计算机的 log₂ 形式，单位 bit；生态文献常用自然对数，H_ln=H_bit·ln 2，均匀度的分子分母必须同底。辛普森模板明确采用 1−Σp²，不混同集中度与倒数形式。米氏模型使用初速，Hill 系数不自动等于位点数。膜平衡电位方向为膜内减膜外、离子价数带符号。qPCR 的 2^(−ΔΔCt) 要求目标与内参效率相近且接近 100%，并明确 Ct 相减方向。SIR 使用人数和 βSI/N，参考讲义中的比例变量按恒定总人口换算，因此 R₀=β/γ；累积发病比例的分母是期初风险人数，不是人时。

主要参考：[OpenStax Biology 2e](https://openstax.org/books/biology-2e/pages/1-introduction)、[Washington 群体遗传课程](https://si.biostat.washington.edu/sites/default/files/modules/2016_SISG_2_4_0.pdf)、[MIT 酶催化](https://ocw.mit.edu/courses/5-60-thermodynamics-kinetics-spring-2008/resources/lec_35/)、[MIT Hill 结合模型](https://ocw.mit.edu/courses/20-109-laboratory-fundamentals-in-biological-engineering-spring-2010/pages/labs/module-2-day-8-data-analysis/)、[Tennessee 多样性指数](https://lgross.utk.edu/bioed/bealsmodules/shannonDI.html)、[Maryland 辛普森指数](https://www.mdsg.umd.edu/topics/k-12-lesson-plans/biofilms-and-biodiversity/try-these-data)、[USGS Chapman 估计](https://pubs.usgs.gov/publication/ofr20221117/full)、[Portland State 物种面积曲线](https://web.pdx.edu/~rueterj/courses/objects/species-area-curve.html)、[Harvard BioNumbers Q10](https://bionumbers.hms.harvard.edu/bionumber.aspx?id=105005&ver=5)、[MIT 膜能斯特方程](https://ocw.mit.edu/courses/7-29j-cellular-neurobiology-spring-2012/resources/mit7_29js12_quikiedrvnern/)、[qPCR 原始方法论文](https://pubmed.ncbi.nlm.nih.gov/11846609/)、[MIT SIR 模型，第 24–25 张幻灯片](https://ocw.mit.edu/courses/1-022-introduction-to-network-models-fall-2018/fe3c864fd7d2d45ed7fe65e601d9c69e_MIT1_022F18_lec20.pdf)、[CDC 发病比例定义](https://archive.cdc.gov/www_cdc_gov/csels/dsepd/ss1978/lesson3/section2.html)。其他条目的原始来源保存在模板详情中。
