# 通用表达工具、化学表达式与轻量流程图

本轮实现跨专业共用的表达能力和化学／流程图首版，核对日期为 2026-10-16（Asia/Shanghai）。原有九专业、235 条模板继续使用。版本保持 1.4.0，本次不生成发布包；全部编辑与输出离线运行。

## 表达工具

点击源码框上方“表达工具”，选择类型。打开时绑定当前源码选区，预览本身不改稿；“插入源码”替换选区，Ctrl+Z 可整次撤销。打开后原稿发生变化时，旧选区会失效，需“使用当前位置”重新绑定。工具只生成表达式，不计算数值或证明推导。

| 类型 | 填写内容与约定 |
|---|---|
| 数值与单位 | 数值或变量使用 LaTeX；单位单独填写为正体。示例 `9.81` 与 `m s^-2`、`kg m/s^2`、`µmol/L`、`°C`。单位留空时只输出数值；不换算单位。 |
| 科学记数法 | 十进制尾数、−999…999 的整数指数和可选单位；生成“尾数 × 10 的整数次幂”。保留尾数，不自动归一化或确定有效数字。 |
| 多行推导 | 每行左式、关系、右式及可选文字说明，沿关系符对齐。后续行左式可空，右式必填；文字说明先转义再排版。 |
| 分段函数 | 函数名、每段表达式和条件。条件可用数学源码，也可关闭勾选按普通文字输入；与推导行分别保存。 |
| 带条件表达式 | 表达式及括号中的条件，可选数学／文字形式。条件仅展示，不自动检查是否成立。 |
| 化学表达式 | 使用 mhchem 的化学输入语法，生成 `\ce{…}`；提供七个示例。 |

多行推导及分段函数各最多 10 行，每行字段最多 1024 个 UTF-16 单元；化学表达式最多 4096 个，单位最多 160 个。工具数据总量上限 32768 个 JSON 字符，生成源码仍须不超过 4096 个 UTF-16 单元。普通数学片段不接受越出所在单元的 `&`、外层换行、未配对环境和宏定义；使用填写器新增行。

单位采用常用符号词表及前缀，支持空格、`·`、`*` 表示乘积，`^` 后的整数表示幂，最多一条 `/` 表示分式。`um`、`µm`、`μm` 均排为微米；`m` 与 `M` 大小写有别。此处不是完整单位语义系统，也不做量纲检查。

生成结果进入原公式编辑流程，继续使用源码复制、命名收藏、历史和 PNG 输出，不引入新的收藏文件格式。工具字段随草稿保存，关闭后保留；输入中的中文组字尚未完成时暂停生成可操作预览。

## 化学表达式

可从“表达工具 → 化学表达式”进入，也可在公式库勾选化学专业后点击“化学表达式”。填写器内部无需写外层 `\ce{}`；直接在主源码框输入时需保留外层。

```latex
\ce{H2O}
\ce{Fe^3+ + SCN- <=> FeSCN^2+}
\ce{^{14}_{6}C -> ^{14}_{7}N + e-}
\ce{Ag+(aq) + Cl-(aq) -> AgCl(s) v}
\ce{2 H2O2 ->[MnO2] 2 H2O + O2 ^}
\pu{1.2e3 kJ/mol}
```

支持下标、离子电荷、同位素、物态、可逆与单向箭头及箭头条件，保持化学元素正体。加载不同示例前确认替换。语法错误保留原文，暂停插入及图片输出；原有外链、HTML、资源与展开限制继续生效。

使用现有 KaTeX 0.19.0 随附的 mhchem 扩展，无新增依赖包或在线服务。上游说明：[KaTeX Extensions](https://katex.org/docs/libs.html)、项目依赖中的 `node_modules/katex/contrib/mhchem/README.md`。扩展许可和上游署名纳入第三方声明生成流程。

这里的语法解析不能判断化学事实、反应条件、质量守恒或电荷守恒；不自动配平，不绘制有机分子结构，不作实验建议。

## 轻量流程图

顶部切换“流程图”，使用独立节点／连线表单。节点支持开始结束、处理、判断、输入输出四种形状，节点文字可换行；连线选择起点、终点和可选说明。顺序、判断、算法循环、实验步骤、管理审批五个示例可以直接加载，替换前确认。

增加、删除、编辑和示例替换均可用“撤销操作／重做操作”，或 Ctrl+Z、Ctrl+Y／Ctrl+Shift+Z；输入法组字期间不截断输入。删除节点同时删除引用它的连线，并先确认。自动布局对跨越中间步骤的边和回边使用外侧路线；复杂、稠密的图仍可能交叉或出现文字靠近连线的情况，首版没有手动拖动、避障优化和语义校验。

输出提供：

- **复制图片／保存 PNG**：使用当前字号、文字颜色、背景、留白、倍率；透明背景保留透明像素。主进程重新校验节点数据，再生成图片，不接受用户 HTML 或 SVG。
- **复制可编辑内容**：复制本工具的节点与连线 JSON。展开“从已复制的内容恢复”，粘贴后点击恢复，可在另一个工作区接着修改。该文本不是 Mermaid 语法，不会执行代码。

最多 24 个节点、48 条连线；节点文字 120、连线文字 40 个 UTF-16 单元，单份结构 JSON 最多 32768 个字符。节点可暂时空白并保存草稿，但图片输出前须补全。图片仍受单边 8192 像素和总计 1600 万像素限制，当前字体和倍率会影响是否超限；超限明确拒绝，不裁切成品。长图在预览中滚动查看。

节点标签按纯文本显示，`<img>`、HTML 和 `$…$` 均不会作为可执行内容或数学语法处理。使用程序生成的受限 SVG 作内部布局，无第三方在线布局依赖；首版对外输出 PNG 和可编辑内容。通用流程图不能替代电路图、受力图、专业工艺管线图、分子结构图或医学／实验判断。

## 保存、兼容与后续阶段

关闭面板和模式切换保留各自内容；开启自动恢复时，表达工具、流程图与当前面板随工作区版本 1 快照保存，纳入原有容量、关闭保存和清除流程。旧草稿没有新字段时仍可读取；新工具采用初始示例。清空工作区会重置表达工具和流程图及其撤销历史，不删除已有公式收藏。

通用表达、化学表达式和通用流程图已实现。后续扩展现已加入 27 套专业完整案例，以及独立的控制框图、受力图和遗传杂交图编辑器，详见 [成套案例与专业绘图说明](成套案例与专业绘图说明.md)；通用流程示例仍使用自己的节点与连线结构。

验证命令为 `npm test`、`npm run build`、`npm run test:expression`、`npm run test:professional`。实际执行结果见根目录 `VALIDATION.md`；桌面测试使用隔离资料和替代保存对话框返回值，不能代替真实输入法、干净系统安装或手工系统对话框验证。
