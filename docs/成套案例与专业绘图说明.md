# 专业成套案例与专用绘图

此版本在原有 235 个独立公式模板之外增加 **27 套完整教学案例**，以及 **控制框图、受力图、遗传杂交图** 三种专门编辑器。全部离线运行，不改变自定义命令、收藏、历史文件格式，不生成安装包，项目版本仍为 1.4.0。

已构建的项目可用 `npm run preview:specialty` 打开隔离试用窗口，初始展示负反馈框图，并备好斜面受力、双位点杂交的编辑状态。资料保存在 `.test-profile/cases-diagrams-preview`，再次运行继续使用现有试用草稿，不覆盖主工作区。该窗口的输入与截图快捷键分别为 Ctrl+Alt+Shift+F13、Ctrl+Alt+Shift+F14。

## 成套案例

从源码区“成套案例”，或模板库内的同名按钮进入。选择专业，可用中文、英文及空格分隔的多关键词搜索，全部匹配结果均可浏览。每套案例包含已知量、问题、适用条件、三步推导、结论及方法来源。

| 专业 | 三套案例 | 主要复核结果 |
|---|---|---|
| 数学 | 二次方程；等比求和；多项式切线 | 根 2、3；和 93；切线 y=10x−16 |
| 物理 | 水平物体受力；动能与净功；等温理想气体 | 4 m/s²；16 J；终态 124.71 kPa |
| 计算机 | 告警贝叶斯后验；一次梯度下降；二元信源熵 | 15.38%；θ₁=0.6；0.8113 bit |
| 电子信息与自动化 | 电阻分压；RC 充电；单位负反馈 | 4 V；τ=0.1 s；T(s)=2/(s+3) |
| 统计学 | 样本均值方差；已知 σ 的均值区间；二项概率 | 均值 4、s²=4；[48.04,51.96]；20.48% |
| 机械、土木与工程力学 | 拉杆应力伸长；梁弯曲应力；斜面下滑 | 100 MPa、1 mm；−10 MPa；3.206 m/s² |
| 化学、化工与材料 | 溶液浓度；储备液稀释；一级反应 | 0.200 mol/L；12.5 mL；半衰期 3.466 min |
| 经济学与管理学 | 两期 NPV；保本销量；经济订货批量 | 41.32 元；200 件；连续解约 707.11 件 |
| 生物学 | 单因子杂交；米氏初速；瞬时种群增长 | 1:2:1 基因型份额；60 μmol/min；80 个体/年 |

“插入推导公式”只将该案例的三行推导插入打开面板时的源码选区，作为一次撤销操作；浏览不改原稿。源码版本变化时拒绝旧选区，可重新绑定当前位置。源码总长仍限 4096 个 UTF-16 单元。完整题干与条件可通过“复制案例全文”保留，复制文本包含 LaTeX 推导和方法来源。案例数值及讲解由本项目原创编写，来源用于说明方法，不是抄录教材例题。

案例是固定数值的教学示范。插入后可以编辑公式和导出图片，**修改已知量不会自动重算案例结论或配套图**。水平受力、斜面、反馈与杂交案例可打开对应绘图预设；预设将替换该类绘图，内容不同时先确认，替换后可撤销。另两类绘图的状态保留。

## 专业绘图

源码区“专业绘图”打开编辑器，通用“流程图”面板也有“控制／受力／遗传图”入口。编辑器内可切换三种绘图类型，三类内容分别保留，不增加新的工作模式。提供七个预设：单位负反馈、正反馈符号对照、水平受力、30° 斜面、Aa×Aa、AaBb×AaBb 和 AaBb×aabb。

### 控制框图

使用固定单环结构：参考输入 → 求和点 → 控制器 C → 被控对象 G → 输出，经 H 反馈到求和点。可修改各框和输入输出的纯文本标签，选择负反馈或正反馈。

- 负反馈关系为 Y/R=CG/(1+CGH)，正反馈关系为 Y/R=CG/(1−CGH)。关系中的 C、G、H 代表相应框体，不解析用户填写的标签。
- 假设单输入单输出、线性时不变、零初始条件，分母非零处有定义；编辑器不求解极点、判稳或整定控制器。
- 框内标签最多 24、标题最多 40 个 UTF-16 单元，长标签换行。标签为普通文字，不执行 LaTeX、HTML 或代码，不支持任意多环结构和拖动连线。

### 受力图

以一个研究对象作为质点，绘制 1–8 个从中心出发的外力。每个外力有名称、大小（N）和方向角；方向角从水平 +x 轴逆时针计算，0° 向右、90° 向上、180° 向左、270° 向下。

- 力的大小须为正且不超过 10⁶ N；方向角范围 −360° 至 360°。空数字可以暂存草稿，但补全前暂停图片输出；非法范围明确报错。
- 所有箭长按当前最大外力统一缩放，图例序号对应箭头。图例数值展示到最多六位有效数字，角度最多四位小数，状态与可编辑文本保留原数值。
- 可关闭坐标轴和图例中的大小显示。箭头方向或大小相近时仍可能重合；极小力的箭头可能不易辨认。绘图不自动补重力、支持力或摩擦力，不判断平衡，不计算合力、应力、力矩或加速度，也不代替梁、桁架及接触力分析。
- 仅填研究对象实际受到的外力，不把合力再次当作外力，不把同一作用反作用力对画到一个对象上。斜面预设中重力竖直向下、支持力垂直斜面、滑动摩擦力沿斜面向上。

### 遗传杂交图

输入一至两对常染色体等位基因，如 Aa、AaBb。每对是同一个英文字母的大写或小写，不同位点用不同字母；两个亲本的位点数量、字母和排列顺序须相同。支持 aa、AA、aA 等写法，格内同一位点规范为大写在前。

- 单位点生成 2×2 组合表，双位点生成 4×4 组合表，并汇总各基因型份额。重复配子按原份额保留，因此 aa×AA 也显示四格 Aa，概率为 4/4。
- 模型假设等概率分离、随机受精、双位点独立分配，无连锁、选择、突变或配子存活差异。大小写只代表等位基因，不自动声明完全显性，不推断表型或实际后代数，不处理性连锁、多等位基因或遗传咨询。

## 输出、恢复与边界

三类绘图均可撤销／重做（Ctrl+Z、Ctrl+Y／Ctrl+Shift+Z）、复制图片、保存 PNG、复制可编辑 JSON，并粘贴恢复继续编辑。导出采用当前图片字号、颜色、背景、留白和倍率；透明背景可用。长图在预览中滚动查看。主进程重新验证数据并生成 SVG，只接受结构化状态，不接受用户 HTML 或 SVG。首版不导出 SVG、Mermaid 或工程 CAD 文件。

预览默认适应当前宽度，方便窄窗口查看全图；关闭“预览适应宽度”可按实际大小滚动查看，预览缩放不改变导出尺寸。图片沿用单边 8192 像素、总计 1600 万像素上限；字号、留白和倍率合并后超过限制会拒绝输出，不裁切。保存对话框取消不写文件。关闭保留内容；启用草稿时三类绘图状态与打开面板写入版本 1 的可选字段，旧草稿缺失时使用初始值。清空当前工作区与草稿会同时重置三类图及其撤销历史。单份可编辑恢复文本上限 32768 个字符，工作区仍受原有 256 KiB JSON 容量限制。案例浏览、筛选与预览适宽开关不写入草稿。

## 方法来源及复核

案例逐条记录关联公式的稳定 ID 和来源；定义见 `src/core/professional-cases.ts`，原公式来源见相应专业目录。数值通过独立算式复核，各专业的单位、正负号、置信区间和模型限制一并检查。新增图形均由项目自行绘制，不复制教材图片。

- 控制：[University of Michigan Control Tutorials](https://ctms.engin.umich.edu/CTMS/?example=Introduction&section=ControlSystemDesign)，补充核对 [MIT 6.302 Recitation 3](https://ocw.mit.edu/courses/6-302-feedback-systems-spring-2007/fe26b88c5112377fd6044bc145dd4d47_6_302rec3.pdf)。本轮 CTMS 直连返回 403，未将其记录为成功抓取；MIT 资料用于交叉核对反馈消元关系。
- 受力：[OpenStax University Physics 1 §5.7](https://openstax.org/books/university-physics-volume-1/pages/5-7-drawing-free-body-diagrams)，斜面采用质点、动摩擦和垂直方向平衡。
- 遗传：[OpenStax Biology 2e §12.3](https://openstax.org/books/biology-2e/pages/12-3-laws-of-inheritance)，限定模型下枚举独立配子组合。
- 计算机：[Dive into Deep Learning · Gradient Descent](https://d2l.ai/chapter_optimization/gd.html)，一次更新独立计算，信息熵采用 log₂。
- 统计：[NIST §7.2.2](https://www.itl.nist.gov/div898/handbook/prc/section2/prc22.htm)，已知总体标准差的均值模型；95% 解释为重复抽样覆盖率。
- 化学：[OpenStax Chemistry 2e §12.4](https://openstax.org/books/chemistry-2e/pages/12-4-integrated-rate-laws)，一级反应条件与半衰期；酶动力学另见 [MIT 5.60 Lecture 35](https://ocw.mit.edu/courses/5-60-thermodynamics-kinetics-spring-2008/resources/lec_35/)。

验证命令：`npm test`、`npm run build`、`npm run test:specialty`，以及既有 `test:expression`、`test:professional` 回归。实际验证记录见 `VALIDATION.md`，专项报告为 `test-results/specialty-report.json`。桌面自动化使用隔离资料及替代保存对话框；真实输入法输入、多显示器、干净系统安装和手工文件对话框仍需实机检查。
