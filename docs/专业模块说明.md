核对日期：2026-10-16（Asia/Shanghai）。本次仅更新源码与本地构建，不更新发布版本或发布包。

## 当前九专业目录

当前共 235 个独立公式模板。数学 10 个，物理、计算机、电子信息与自动化、统计学、机械／土木／工程力学、化学／化工／材料、经济管理、生物学各可浏览 30 个。九专业入口合计 250 个，其中 15 个入口共享已有定义。新四专业的内容、约定和来源见 [四专业扩展说明](四专业扩展说明.md)。

## 电子信息与统计学扩展

这一批引入电子信息 30 条与统计学 24 条新定义、6 个共享入口；当时全库为 124 条。下列目录仍有效，后续四专业采用同一共享机制。

电子信息与自动化包括以下六个主题，每主题 5 个：

| 主题 | 模板 |
|---|---|
| 电路基础 | 欧姆定律、基尔霍夫电流定律、基尔霍夫电压定律、电阻分压、RC 充电响应 |
| 交流与暂态 | 串联 RLC 阻抗、相量欧姆定律、交流有功功率、LC 谐振角频率、RL 电流阶跃响应 |
| 信号与变换 | 连续时间卷积、连续傅里叶变换、双边拉普拉斯变换、双边 Z 变换、理想采样率条件 |
| 自动控制 | 传递函数、负反馈闭环传递函数、连续 PID 控制律、连续状态空间模型、标准二阶系统 |
| 通信原理 | 常规调幅信号、调频信号、相干 BPSK 误码率、香农信道容量、奈奎斯特无噪声码率 |
| 数字信号处理 | 离散傅里叶变换、离散傅里叶逆变换、离散时间线性卷积、FIR 滤波器传递函数、IIR 差分方程 |

前两主题为基础，其余为进阶。电路采用被动符号约定；正弦相量采用 e^{jωt}、j²=−1。傅里叶变换以 f（Hz）为自变量，DFT 正变换负指数、不带归一化系数，IDFT 正指数、带 1/N。双边变换必须另给收敛域。控制模板明确零初始条件、反馈方向及模型假设，不自动整定参数或保证闭环稳定。通信公式注明有效值、线性功率比、噪声谱约定及理想信道假设。

统计学包括以下六个主题，每主题 5 个：

| 主题 | 模板 |
|---|---|
| 描述统计 | 样本均值、样本方差、样本标准差、样本协方差、皮尔逊相关系数 |
| 概率分布 | 正态分布（共享）、二项分布、泊松分布、指数分布、连续均匀分布 |
| 概率与抽样 | 条件概率（共享）、全概率（共享）、贝叶斯（共享）、均值标准误估计、中心极限定理 |
| 参数估计 | 独立样本似然函数、最大似然估计、已知方差均值置信区间、未知方差均值置信区间、正态总体方差置信区间 |
| 检验与方差分析 | 单样本 t 检验、Welch 双样本 t 检验、列联表独立性检验、卡方拟合优度、单因素 ANOVA |
| 回归与拟合 | 线性回归（共享）、均方误差（共享）、简单 OLS 斜率、决定系数、回归残差 |

前三主题为基础，其余为进阶。样本方差采用 n−1 分母；均值标准误与观测标准差分开说明；指数分布使用速率参数 λ。所有置信区间采用下侧累计概率分位数，χ² 区间的较大分位数位于下限分母。Welch 模板同时提供统计量和近似自由度；ANOVA 明确等方差假设。R² 不承诺在所有模型和测试集上非负。模板只生成表达式，不进行显著性判断、估计计算或因果推断。

## 工作模式与专业模块

当前“公式”“伪代码”“流程图”是三种工作模式；前文九专业是可组合的内容模块。伪代码和流程图使用独立抽屉，顶部“返回公式模式”回到原源码；关闭不清除内容。数值单位、多行推导、分段函数、条件和化学表达式属于公式模式中的“表达工具”，详细用法见 [表达工具与流程图说明](表达工具与流程图说明.md)。

公式库未勾选专业时显示全部，勾选多个时取并集，再与主题、难度和搜索词交集。多个空格分隔的搜索词需同时匹配。精确名称或别名优先，其余按目录顺序显示，结果不截断。

## 伪代码约定

示例用英文结构关键词、中文说明。`//` 表示注释，缩进每级两空格；编辑器只负责排版，不检查结构是否闭合或执行算法。示例为本项目编写：二分查找使用闭区间和 0 起始下标；归并排序切片左闭右开；BFS 入队时标记；DFS 的内部访问过程共享状态；梯度下降执行固定次数，不声称任意目标均收敛。

行内公式使用 `$…$`，原始纯文本复制保留定界符。`\$` 显示普通美元符号。数学错误保留原文并标记行号，图片输出须等所有行无错误后进行。Tab 字符允许输入，显示宽度为两空格。超长输入保留最近有效文本。

运行时不访问来源网站。参考网址是查证信息，不是运行依赖。图片输出沿用全局图片样式和尺寸限制，过高或过宽的伪代码需缩短后导出。当前不支持分页导出、论文 LaTeX 算法环境、代码执行、伪代码收藏及伪代码历史。
