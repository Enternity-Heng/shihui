# 式绘

Windows 上的离线公式、算法与科学绘图工作台。简单公式转成可编辑的文字符号，复杂公式排版成图片；支持截图识别、历史、自定义命令、可填写公式模板、命名收藏、图片样式和中文符号搜索。输入快捷键 **Ctrl + Alt + M**，截图快捷键 **Ctrl + Alt + S**。

## 1.5.0：公式、算法与科学绘图工作台

采用“式绘”作为新名称：“式”对应公式与表达，“绘”对应算法排版和专业图示。新图标以 Σ 与连接节点组合，延续原有蓝白配色。公式工具集中在独立一行；源码栏保留搜索与字数信息，避免入口挤占编辑位置。最小窗口中识别按钮显示图标，悬停可查看用途；所有入口可键盘访问。

安装包为 `式绘-1.5.0-Setup-x64.exe`，解压版为 `式绘-1.5.0-Windows-x64.zip`。程序标识、`MathInputAssistant.exe` 和原用户数据目录保持兼容，升级继续读取已有设置、收藏与草稿。

新增“成套案例”和“专业绘图”：九个学科各 3 套完整案例，共 27 套，包含已知量、条件、推导、结论和方法来源，可搜索、复制全文、插入推导或打开配套图。专业绘图提供控制框图、质点受力图和单／双位点遗传杂交图，含七个预设，支持编辑、撤销重做、透明 PNG、可编辑内容复制恢复和草稿保存。具体目录、模型条件和边界见 [成套案例与专业绘图说明](成套案例与专业绘图说明.md)。案例为固定教学示范，修改公式不自动重算；专业图不执行工程或生物学判断。

顶部提供“公式／伪代码／流程图／专业绘图”四个工作入口。数学、物理、计算机、电子信息与自动化、统计学、机械／土木／工程力学、化学／化工／材料、经济学／管理学、生物学作为公式库中的九个专业模块，可同时筛选；四个工作入口保留各自编辑内容。1.5.0 将上述专业扩展合并进正式安装包和解压版。

新增“表达工具”：数值与正体单位、科学记数法、多行推导、分段函数、带条件表达式和化学表达式。填写后预览，插入当前源码选区并整次撤销；源码变化时重新绑定。化学支持 `\ce{...}`、`\pu{...}`，也可从化学模块进入填写器，含七个示例；不自动配平或判断反应正确性。表达式可复用原公式收藏与图片导出。

“流程图”模式采用节点和连线表单，支持顺序、分支、循环与五个示例；可撤销／重做、复制图片、保存 PNG、复制可编辑内容并粘贴恢复。最多 24 个节点、48 条连线，沿用图片样式与尺寸上限；表达工具、流程图及打开面板随版本 1 草稿保存，旧草稿缺少新字段时按初始内容处理。关闭保留内容，清空工作区会一起重置。用法和首版边界见 [表达工具与流程图说明](表达工具与流程图说明.md)。

点击“公式模板库”浏览全部 **235 个独立模板**：数学模块 10 个，其余八个模块各 30 个入口。跨专业共用 15 个入口，因此专业数量相加不等于独立模板数；同时选择多个专业时，共享条目只显示一次，按当前专业展示对应主题。支持中英文关键词、多个专业、主题与基础／进阶筛选，全部匹配项都可浏览。详情包含预览、专业归属、变量说明、适用条件和参考来源；点击“插入并填写”替换打开模板库时的源码选区，随后用 Tab／Shift+Tab 填写，同编号变量联动，插入可整次撤销。源码已变化时需点击“使用当前位置”重新绑定。浏览本身不改稿、不复制，也不向外部软件插入。

物理覆盖力学、热学、电磁学、振动与光学、量子力学、狭义相对论；计算机覆盖逻辑与集合、算法与图论、组合与概率、信息论、学习与优化、深度学习。专业模板独立于自定义命令，不占用新增命令名。电磁学采用 SI 制，场方程使用积分形式；热学约定吸热为正、系统对外做功为正；信息论以 2 为对数底、单位 bit。各模板的限制以详情说明为准。内容与核对记录见 [专业模块说明](专业模块说明.md)。

电子信息与自动化新增电路基础、交流与暂态、信号与变换、自动控制、通信原理、数字信号处理六个主题，各 5 个模板，包含 PID、状态空间、DFT／IDFT、信道容量等。相量采用 e^{jωt} 约定；傅里叶变换使用 f（Hz），电路角频率使用 ω（rad/s）；双边拉普拉斯／Z 变换需说明收敛域，功率有效值、线性信噪比等条件在详情中明确。

统计学包含描述统计、概率分布、概率与抽样、参数估计、检验与方差分析、回归与拟合六个主题，各 5 个模板。24 条为新增，正态分布、条件概率、全概率、贝叶斯、线性回归和均方误差共 6 条直接共享原模板与稳定 ID。提供均值、方差、相关系数、置信区间、Welch 检验、ANOVA、决定系数等表达式；样本独立性、正态性、等方差要求和分位数方向以详情为准。本次只提供公式输入排版，不自动计算检验结果或作统计决策。

新增四专业各分六主题、每主题 5 个：机械／土木／工程力学覆盖静力、材料变形、梁与扭转、流体水力、结构土力及机械振动；化学／化工／材料覆盖计量溶液、热力学平衡、反应器、电化学分析、传递分离及材料性能；经济管理覆盖供需、生产市场、宏观核算、增长货币、项目决策和运营；生物覆盖遗传、细胞酶、种群生态、多样性、生理及实验传播模型。本轮 120 个入口中新增 111 条、共享 9 条；目录、共享 ID、符号约定和来源说明见 [四专业扩展说明](四专业扩展说明.md)。

顶部“伪代码”或公式库中的“打开伪代码编辑器”进入独立编辑区，点击“返回公式模式”返回。支持中文注释、两空格缩进、Tab／Shift+Tab、Enter 延续缩进、Ctrl+Z／Ctrl+Y 撤销重做。可加载二分查找、归并排序、BFS、DFS、梯度下降五个示例；替换已有不同内容时确认，替换后可撤销。

用 `$x^2$` 在同一行嵌入数学公式，`\$` 表示普通美元符号。不支持跨行公式或 `$$…$$`。语法错误显示所在行并暂停图片输出，仍可复制原始纯文本。纯文本保留数学定界符、不含展示行号；图片和 PNG 包含当前行号设置，沿用图片样式。伪代码最多 16000 个 UTF-16 单元、200 行；图片仍受单边 8192 像素及总计 1600 万像素限制，超限提示缩短内容，不裁切。

启用草稿恢复时，伪代码内容、选区、行号及打开状态随工作区保存；关闭面板保留内容，“清空当前工作区与草稿”同时清除公式与伪代码。专业库筛选只在本次运行中保留。伪代码不加入公式收藏或历史，不执行、调试算法，不判断正确性，不导出 algorithmicx／algorithm2e。

开发环境已准备好时，运行 `npm run build` 后执行 `node node_modules/electron/cli.js .` 启动；公式与伪代码专项使用 `npm run test:professional`，表达与流程图使用 `npm run test:expression`，案例与专业绘图使用 `npm run test:specialty`，分别写入 `test-results/professional-report.json`、`test-results/expression-report.json` 与 `test-results/specialty-report.json`。桌面测试使用独立配置，会暂时写入剪贴板并打开测试窗口。

## 1.4.0：公式匣

数学输入助手现更名为 **公式匣**，采用新的图标和紧凑浅色界面。应用标识、可执行文件名和原有用户数据目录保持兼容，升级继续读取旧收藏、命令、设置与历史。安装包名称变为“公式匣-1.4.0-Setup-x64.exe”，解压版为“公式匣-1.4.0-Windows-x64.zip”。

### 矩阵与方程组

点击公式工具行的“矩阵／方程组”。矩阵支持 1～10 行、1～10 列，六种括号／行列式样式；空格按 0 生成。方程组每行填写一条完整等式或不等式，最多十行。可实时预览，确认后在原选区插入，Ctrl+Z 一次撤销。缩减尺寸会丢弃非空内容时先确认；源稿发生变化时拒绝按旧选区插入，需重新选择插入位置。关闭面板保留填写内容，首版不解析任意已有矩阵，也不求解方程。

### 联动模板

自定义模板可写成 `\frac{${1:a}}{${1}}$0`。使用美元符号占位语法定义与引用同一个变量后，填写任一处会同步镜像；Tab 跳过重复镜像进入下一个变量。Esc、跨字段编辑、撤销或重做结束联动。普通源码里的同名字符不会自动替换。单次编辑及展开结果均受 4096 个 UTF-16 单元限制。

### 分类与备份

收藏面板支持单层分类、未分类筛选、改名与移动；删除分类只把收藏移到未分类。最多 50 类、200 条收藏，收藏名称全局唯一。点击“备份收藏”导出 JSON，或“导入备份”查看合并摘要后确认。备份仅包含收藏与分类，不含历史、命令、设置和草稿。重名不同源码会添加数字后缀，重复导入同一备份不会不断产生副本。导入上限 8 MiB；未知版本、损坏、超限或悬空分类整批拒绝。数据已迁移后，不要用旧程序编辑新版收藏库；回退前先导出备份。

### 识别核对

识别成功后保留主编辑器的原稿，在核对面板查看完整参考图，支持缩放、平移、修改源码和实时预览。注意分数、根号、上下标及相似符号；本工具不提供逐字符置信度，也不保证数学内容正确。只有“确认并应用”才回填并尝试记录历史，不会自动复制或插入。Esc 或“暂存关闭”保留待核对结果；修改后“放弃结果”需要确认。清空历史、关闭记录会阻止旧结果随后补写；核对恢复后需重新从目标软件呼出才能插入。原图缺失时会提示并保留文字。

### 草稿与设置

默认自动保存当前源码、光标／选区、有效模板状态、填写器和待核对结果（含参考图）。正常编辑约 500ms 合并写入，持续输入最长约 2 秒触发保存；状态栏显示保存结果。隐藏及正常退出提交最新稳定快照；强制结束只能恢复最近成功落盘版本，组字中或尚未落盘的输入可能丢失。不恢复外部插入目标、撤销栈或进行中的任务，不会重启识别或自动粘贴。

草稿独立于历史：关闭历史仍保存草稿。设置→通用设置可停止自动恢复并删除已存草稿，此操作保留当前编辑内容；“清空当前工作区与草稿”则同时清空源码、填写器、核对结果、备份和参考图。遇到保存失败可点击“重试保存”。草稿 JSON 上限 256 KiB、参考图沿用 20 MiB 图片限制、目录预算 64 MiB；超限会提示，不能当作已保存。

设置分为通用、自定义命令、图片样式三个页签，切换页签保留未保存输入。主窗口底部操作区固定，中间区域在较小窗口内滚动，支持键盘导航与减少动画偏好。公式图片颜色和背景独立于界面配色。


## 给使用者

无需安装 Node.js、Python、LaTeX 或任何开发环境，运行期间无需联网。

### 安装版

双击 `式绘-1.5.0-Setup-x64.exe`，按提示安装，然后从桌面或开始菜单启动。默认仅安装给当前用户，无需管理员权限。可从 Windows 的“已安装的应用”卸载。

### 解压版

将 `式绘-1.5.0-Windows-x64.zip` **完整解压**到一个文件夹，双击 `MathInputAssistant.exe`。不要只发送或移动其中的 EXE，程序依赖同目录内的 DLL、resources 和 locales。

### 输入数学符号

1. 启动程序。首次出现输入窗口；按 Esc 可以隐藏，程序仍在系统托盘中。
2. 在记事本、浏览器输入框或 Word 普通文本区内，先点击需要输入的位置。
3. 按 **Ctrl + Alt + M**，在弹窗里输入 `\alpha+\beta`。
4. 确认结果为 `α+β`，按回车或点击“插入符号”。

| LaTeX | 结果 |
|---|---|
| `\alpha+\beta` | α+β |
| `x^2+y^2` | x²+y² |
| `x_{max}` | xₘₐₓ |
| `\forall x\in A` | ∀x∈A |
| `\infty` | ∞ |

上下标只有能完整表示时才转成文字。`\frac{1}{2}`、`\sqrt{x}`、`\mathbb{R}`、`\text{a b}` 等保留为完整的排版公式。输入范围是 KaTeX 支持的数学语法，不能编译完整的 LaTeX 文档。

### 复杂公式

从目标软件呼出输入框后，输入 `\frac{-b\pm\sqrt{b^2-4ac}}{2a}` 或 `\begin{pmatrix}a&b\\c&d\end{pmatrix}`，按 **Ctrl+Enter** 或点击“插入图片”，即可将公式图片粘贴回原软件。目标软件必须支持图片粘贴，例如 Word 或支持图片的富文本编辑器；普通文本框不能接收图片。

也可点击“复制图片”后手动粘贴，或保存白底高清 PNG。没有插入目标时，Ctrl+Enter 会复制图片。图片不是 Word 的可编辑公式对象。普通回车仍用于插入文字符号，复杂公式不会因普通回车而意外插入图片；Shift+Enter 可以换行。

复制或插入图片会覆盖系统剪贴板，图片粘贴后仍留在剪贴板，方便目标软件未接收时手动粘贴；插入文字符号不会改变剪贴板。自动粘贴不会自动重试。复制源码得到去除外层数学定界符后的 LaTeX。

### 图片转 LaTeX

1. 点击 **“截图识别”**，或按 **Ctrl+Alt+S**，在冻结的屏幕画面上拖动框选一条公式，松开自动识别。Esc 或右键取消。
2. 也可点击“图片转 LaTeX”后选择“打开图片”导入 PNG/JPEG，或使用“剪贴板图片”。在本工具内可按 **Ctrl+Shift+V** 读取剪贴板图片。
3. 等待离线识别，在核对面板对照原图、修改识别源码并查看预览；点击“确认并应用”后才回填主编辑器。暂存关闭不会丢弃结果，确认前不记录识别历史。
4. 核对分数、根式、上下标和相似符号后，点击“复制源码”。需要插入其他软件时，请回到目标软件重新按 Ctrl+Alt+M 呼出。

识别模型和 CPU 运行库随安装包、解压包一同提供，**识别时无需联网、无需账号、不上传图片**，接收者不需要安装 Python、LaTeX 或额外的运行组件。识别只在点击按钮或快捷键后进行，不自动监控剪贴板。默认保存识别结果及送入识别的原图作为本机历史，可在设置中关闭。

截图支持在任意显示器内部框选，不拼接跨屏选区。采集画面总计最多 6400 万像素；屏幕配置变化或获取超时会取消并恢复窗口。全屏画面仅临时存于内存，历史只保存选区，不改动剪贴板。截图或识别后如需插入外部软件，请重新从目标软件呼出。

### 历史记录

点击右上角“历史”，可搜索 LaTeX 源码、按需预览公式和原图、回填编辑、删除单条或确认后清空。成功复制、发送插入请求、保存 PNG、识别时记录；普通预览、补全和取消操作不记录。插入记录表示已发送请求，无法证明目标软件已接收。

最多保留最近 **500 条公式**，相同源码去除首尾空白后合并并更新使用时间。附图总预算 **512 MiB**，超限清理最旧附图，保留公式并标注“原图已清理”。再次识别同一公式会更新附图；手动修改后的新公式不关联原来的识别图。

关闭“记录使用与识别历史”后停止新增，已有数据仍可查看和删除。清空或关闭记录后，此前启动的任务不会迟到新增。索引损坏时尝试恢复有效备份并保留损坏文件，无法恢复则暂停写入；历史保存失败不会撤销已成功的复制或识别。删除或清空会同时移除旧历史备份，防止恢复出已删除内容。附图缺失时仍可恢复源码。

### 自定义命令与联想补全

在源码框输入命令前缀，例如 `\alp`，用上下键选择候选，**Tab** 或鼠标确认。**Enter 保持插入／复制当前公式的用途，不接受候选**；Ctrl+Enter 操作公式图片。Esc 优先关闭候选或结束模板填写，再次按 Esc 可隐藏窗口。

点击“搜索命令”或按 Ctrl+Space 可按中文关键词搜索，例如“分式”“积分”。输入法若拦截 Ctrl+Space，请使用按钮。设置中关闭“自动联想补全”后仍可手动搜索。候选包含内置符号、结构模板和自定义命令，不推荐历史公式。

点击源码框上方 **“公式模板库”** 可浏览九个专业模块中的 235 个独立可填写模板。数学模块保留求根公式、勾股定理、二项式定理、导数、定积分、分部积分、泰勒展开、等比数列求和、正态分布概率密度和欧拉公式。搜索后选择模板，点击“插入并填写”，Tab／Shift+Tab 在字段间跳转。内置模板中同一编号变量会联动；Esc 或越出字段编辑后结束联动，后续按普通源码编辑。

设置中可新建、编辑、删除命令，例如名称 `RR`、模板 `\mathbb{R}`。名称为 1～32 个英文字母，区分大小写，不能与内置命令同名；最多 200 条。选中后展开为完整 LaTeX，复制和历史无需命令定义，删除定义也不影响旧公式。模板只展开一次，不递归引用其他自定义命令。

模板 `\frac{${1:a}}{${2:b}}$0` 插入后选中分子，Tab 跳到分母，Shift+Tab 返回，完成后到 `$0`。编号限 1～9，`${1:a}` 定义变量，`${1}` 引用同一变量；引用可以在定义之前，同编号重复定义的默认值必须一致。填写期间修改任一镜像会同步其他位置。`$0` 至多一次；不支持嵌套占位符。默认内容允许配对花括号；字面量 `${` 写作 `\${`，字面量 `$0` 写作 `\$0`。编辑越出活动字段时结束跳转并保留文字。默认字段也是实际源码，Enter 会使用当前内容。

Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做，保留最多 100 步；模板插入和历史回填各作为一次操作，撤销／重做会结束占位符模式。展开或输入超过 4096 个 UTF-16 单元时保留原内容。

### 中文符号搜索

点击源码框下方 **“中文符号搜索”**，输入“阿尔法”“不等于”“属于”“偏导”“右箭头”“空集”“无穷大”等中文名称或别名，也可输入“希腊 大写”“集合”“逻辑”“几何”等分类关键词。符号名称、LaTeX 命令和符号本身均可检索，最多显示八个候选，输入更具体的关键词可缩小范围。

上下键选择，Tab 或鼠标确认；插入对应 LaTeX 命令并生成符号预览，不直接向其他软件提交。中文搜索输入框可以正常使用中文输入法。

### 命名收藏与一键复用

输入并预览有效公式后，点击右上角 **“收藏”**，填写名称并保存。收藏最多 200 条，名称最多 64 字，支持按名称或源码搜索、改名、删除及回填编辑，重启后保留。收藏保存完整源码，不依赖命令定义，清空或关闭历史不会删除收藏。

点击 **“一键使用”** 会回填、检查并使用当前公式：从目标软件按输入快捷键呼出时，发送符号或图片插入请求；没有目标时复制符号或图片。目标失效时拒绝自动插入，请重新从目标软件呼出。图片插入需要目标软件支持 PNG 粘贴。收藏统一采用当前图片样式，不保存每条独立样式。

### 图片样式

在设置面板下方调整图片字号（12～72 px）、文字颜色、白底／透明／自定义底色、留白（0～96 px）和导出倍率（1～4 倍），点击 **“保存图片样式”** 生效，也可恢复默认。默认黑字白底、26 px、24 px 留白和 2 倍导出。

样式统一作用于数学公式预览、复制图片、图片插入和保存 PNG，重启后保留。导出倍率只改变图片像素，不改变主窗口缩放；过大图片仍受单边和总像素限制。透明 PNG 保留透明通道，粘贴后的背景显示取决于目标软件。

目前面向**裁剪清晰的单条印刷公式**。整页教材、混排段落、模糊照片、复杂多行公式和手写公式的准确率不作保证。识别结果需要人工核对；它不会自动提交到原软件。取消或失败时保留原源码。

输入图片最多 20 MB，单边最多 8192 像素，总计 1600 万像素。识别最长 90 秒、最多 512 个模型字符单元，超限停止。可点击“取消识别”；大图请先裁剪出所需公式。新增模型会增加分发包体积，解压版需保留整个文件夹，尤其 `resources/ocr` 及运行 DLL。

### 快捷键、托盘和设置

- 右上角“设置”可以修改快捷键，例如 `Control+Shift+K`。新快捷键被占用时保留原快捷键。
- 本机新版 WinUI 记事本会被含 Alt 的组合键激活菜单，影响自动插入；在这类软件中请改用 **Control+Shift+K**，已验证可插入。默认 Ctrl+Alt+M 已在 Edge 与 Word 验证。
- 从托盘打开时默认没有插入目标，可使用复制功能。要插入，请回到目标软件再次按快捷键。
- 切换至其他软件会取消原插入目标，防止使用失效的目标；需重新呼出。
- 关闭窗口或按 Esc 仅隐藏程序；从托盘菜单选择“退出”才会完全退出。
- 默认不开机自启，历史默认开启，原源码编辑框不作为自动草稿持久保存。
- 设置存储在 `%APPDATA%\数学输入助手\settings.json`；命令为 `commands.json`，收藏为 `favorites.json`，历史为 `history.json`，附图为 `history-images`。解压版默认也使用此位置。
- 卸载保留本机数据。清除历史请使用界面按钮；需要完全重置时，退出程序后删除该用户数据目录。高级用法可传入 `--user-data-dir=绝对路径` 使用独立数据目录，测试也使用此方式隔离日常数据。

### 支持范围与限制

目标平台为 Windows 10 22H2 / Windows 11 x64。**实际已测试的系统与软件见同目录《测试记录.md》；目标支持不等于已经完成所有系统的验证。**

模拟输入受到 Windows 权限和控件行为限制，管理员窗口、特殊编辑器及远程桌面可能不接受。插入前会核对目标和可获取的控件焦点，但无法保证恢复控件内部的旧光标或察觉网页内部的所有焦点变化。请在需要的位置先点击，再呼出工具。

如果 Word 粘贴时报告“文件未找到：MathPage.WLL”，这是现有 MathType 加载项缺失组件。图片仍保留在剪贴板；该加载项也可能影响手动粘贴，请按 [MathType 官方说明](https://docs.wiris.com/en_US/run-time-error-53-file-not-found-mathpage-wll)修复现有安装。本工具不会修改 Word 的加载项或宏安全设置。

插入失败或只发送部分字符时，程序不会自动重试或撤销，请检查原文后手动复制。源码上限 4096 个 UTF-16 单元；公式计算最多 2 秒，宏展开最多 1000 次，尺寸参数上限 20em；PNG 单边最多 8192 像素，总计最多 1600 万像素。

本版未进行代码签名，Windows 可能显示未知发布者提示。发布目录的 `SHA256SUMS.txt` 可用于核对文件完整性：

```powershell
Get-FileHash -Algorithm SHA256 '.\式绘-1.5.0-Setup-x64.exe'
```

## 给开发者

需要 Windows x64、Node.js 24 及 npm；首次安装依赖和下载运行时需要联网。使用仓库内的 `package-lock.json`。

```powershell
npm ci
npm run setup
npm test
npm run build
npm run test:desktop
npm run test:zoom
npm run test:ocr
npm run test:features
node scripts/favorites-styles-test.mjs
npm run test:image-insert
npm run test:compatibility
npm start
```

桌面测试会启动项目窗口和一个独立测试编辑器，临时测试全局快捷键及系统剪贴板，请勿在测试期间操作键盘鼠标。测试资料写入 `.test-profile/` 和 `test-results/`，不使用日常配置。

兼容测试还会打开独立 Edge、记事本测试文件及新的 Word 空白文档；检测到已有 Word 进程时会停止 Word 测试，避免影响现有文档。系统安装生命周期验证脚本位于 `scripts/installed-test.mjs`，仅允许安装到工作区测试目录，检测到其他位置已有同名安装时会停止。

图片插入专项测试默认以 Word `/a` 启动临时会话，隔离现有加载项；不修改持久设置。可设置环境变量 `MATH_WORD_WITH_ADDINS=1` 测试本机正常加载项环境。

### 一次生成两个分发包

```powershell
npm run package
```

成品位于 `release/`，包含安装包、解压包、完整源码 ZIP、使用说明、版本、许可证、测试记录及 SHA-256 清单。打包依赖和 NSIS 工具首次使用需要下载；成品运行无需联网。没有配置签名证书时生成未签名版本。

主进程负责系统接口和隔离的公式计算 Worker；界面进程启用沙箱，通过受限 IPC 请求渲染、插入和导出。图片在独立画布中完成排版后导出。调试专用测试接口仅在未打包且设置 `MATH_INPUT_TEST=1` 时存在，发布版不会开放。

公式识别使用 RapidLaTeXOCR 的离线 ONNX 模型及 ONNX Runtime CPU 后端，运行在可终止的独立系统进程中。模型来源、版本及 SHA-256 记录在 `assets/ocr/manifest.json`，构建前校验。完整源码包包含模型与签名已核验的微软运行 DLL，`npm run setup:ocr` 可在模型缺失时下载固定文件并校验；应用运行期间不会下载模型。Windows 运行 DLL 采用应用目录内分发，不安装到系统目录。许可证随成品和源码一同提供。
